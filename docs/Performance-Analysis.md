```
HTML → CSS 加载 → JS 加载 → React 初始化 → 路由渲染 → 首页组件渲染
```

1. **已实现**：

## 运行时性能

### 状态管理

- **Zustand**：轻量级，无 Provider 包裹开销
- **Store 设计**：按领域拆分（chat、project、settings），避免大对象

### 渲染性能

- **组件结构**：扁平化，避免深层嵌套
- **样式方案**：Tailwind 工具类，无运行时 CSS-in-JS 开销
- **图标**：@iconify/react，SVG 图标按需渲染

### 内存占用

- **localStorage**：单个项目约 50-200 KB，支持多项目
- **缓存策略**：无额外内存缓存，依赖浏览器缓存

## 网络性能

### API 调用（Live 模式）

- **流式输出**：SSE，边生成边渲染
- **超时控制**：首字节 20s；流间隔 90s（相邻数据块间隔阈值，每收到 chunk 即重置，非总时长限制；取值依据：实测 Agnes 长输出存在约 38.9s 服务端流停顿且停顿后流仍正常完成，故取实测最大值的 2 倍以上余量）
- **重试策略**：网络错误指数退避，429 按 Retry-After

### 演示模式

- **零网络请求**：完全本地运行
- **响应速度**：模板实例化 < 3s

## 移动端响应式检查

### 当前状态

| 页面/组件 | 移动端适配 | 说明 |
|-----------|------------|------|
| 首页 | 部分支持 | 居中布局在小屏幕可用，但缺少断点优化 |
| 工作台 | 未支持 | 三栏布局固定宽度，无响应式断点 |
| 项目侧栏 | 未支持 | 固定宽度 260px |
| 对话面板 | 未支持 | 固定宽度 400px |
| 预览面板 | 未支持 | 固定最小宽度 480px |

### 问题清单

1. **工作台三栏布局**：在移动端宽度不足，会出现水平滚动
2. **无断点响应**：未使用 Tailwind 的 `md:`、`lg:` 断点前缀
3. **侧栏折叠**：移动端应可折叠，当前固定显示

### 建议改进

1. **首页**：
   - 标题字号响应式调整（42px → 28px）
   - 模板芯片换行优化

2. **工作台**：
   - 移动端侧栏默认隐藏，点击按钮展开
   - 对话面板与预览面板切换显示（Tab 切换）
   - 预览面板占满屏幕

3. **实现方式**：
   ```tsx
   // 使用 Tailwind 断点
   <div className="w-[400px] md:w-[360px] lg:w-[400px]">
   ```
