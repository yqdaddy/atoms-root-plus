# 智能框架自动识别功能

## 功能概述

系统现在可以自动识别用户需求应该使用哪种框架（HTML / React CDN / Vue CDN），无需手动选择。

## 识别规则

### React 框架关键词
- `react`、`jsx`、`react组件`、`React 组件`
- `用 React`、`用react`、`React 做一个`、`react 做一个`
- `React 写`、`react 写`

### Vue 框架关键词
- `vue`、`vue组件`、`Vue 组件`
- `用 Vue`、`用vue`、`Vue 做一个`、`vue 做一个`
- `Vue 写`、`vue 写`、`单文件组件`

### 默认框架
- 未命中关键词时，默认使用 HTML 框架

## 框架选择优先级

1. **用户手动选择**（最高优先级）
   - 用户在框架选择器中明确选择的框架
   - 覆盖所有自动识别结果

2. **意图识别建议**
   - 基于关键词自动识别的建议框架

3. **全局偏好**
   - 用户设置的全局默认框架

4. **默认框架**
   - HTML

## 使用示例

### 示例 1：自动识别 React
```
用户输入："用 React 做一个计数器"
系统识别：React CDN
前端显示："自动识别框架 React ✨"
```

### 示例 2：自动识别 Vue
```
用户输入："用 Vue 写一个贪吃蛇游戏"
系统识别：Vue CDN
前端显示："自动识别框架 Vue ✨"
```

### 示例 3：默认 HTML
```
用户输入："做一个简单的待办事项列表"
系统识别：HTML
前端显示：（无额外提示，使用默认 HTML）
```

### 示例 4：用户手动覆盖
```
用户输入："做一个网页"
用户手动选择：React CDN
系统使用：React CDN（忽略自动识别）
```
