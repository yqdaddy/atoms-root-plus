# Atoms Demo 落地页设计规范

> 作者：dev-atoms-ux-designer
> 版本：v1
> 适用范围：未登录用户首页（Landing Page）
> 本规范继承 `docs/design-system.md` 全部 token 与禁则，落地页专属规则在此补充。

## 0. 设计定位

### 0.1 页面角色

落地页是用户首次进入产品的第一触点，承担三个任务：
1. 快速传达产品价值（一句话说清"这是什么"）
2. 展示核心能力（为什么选我们）
3. 引导注册/登录（转化为活跃用户）

### 0.2 与工作台的关系

落地页是"入口"，工作台是"产品"。设计语言必须统一：
- 相同 token（色彩/字体/圆角/间距）
- 相同反 AI 味基线
- 落地页允许更宽松的留白节奏（营销属性）

### 0.3 反 AI 味特化

落地页是 SaaS 营销页，需额外注意：
- 禁止 hero 区紫蓝渐变光斑（LILA 规则）
- 禁止三张同款功能卡片横排（AI 套版签名）
- 禁止每个标题上方加 eyebrow 标签
- 禁止夸饰文案（"无缝释放下一代 AI 生产力"）
- 禁止假精确数字（"99.99% 可用性"）

## 1. 布局结构

### 1.1 页面模块顺序

```
┌─────────────────────────────────────────────────┐
│  Header（品牌 Logo + 导航 + CTA）               │
├─────────────────────────────────────────────────┤
│  Hero 区（品牌名 + 价值主张 + CTA）             │
├─────────────────────────────────────────────────┤
│  功能特性区（核心能力展示）                     │
├─────────────────────────────────────────────────┤
│  演示截图区（产品界面展示）                     │
├─────────────────────────────────────────────────┤
│  Footer（版权 + 链接）                          │
└─────────────────────────────────────────────────┘
```

### 1.2 响应式断点

| 断点 | 条件 | 布局变化 |
|---|---|---|
| 桌面 | >= 1024px | Hero 区左右双栏，特性卡片三列 |
| 平板 | 768px - 1023px | Hero 区上下叠放，特性卡片两列 |
| 手机 | < 768px | 单栏流式，特性卡片单列 |

### 1.3 最大内容宽度

- 内容容器：max-w-7xl（1280px），左右 auto 居中
- 内边距：px-6（24px），手机 px-4（16px）

## 10. taste-skill 自检清单

逐条回答，确保落地页不含 AI 生成味：

| 检查项 | 结果 |
|---|---|
| 换个 AI 会不会生成一模一样的界面？ | 否。非对称特性布局、纯色背景、atom 绿强调色、Space Grotesk 字体形成独特身份。 |
| 主色是否有品牌理由？ | 是。atom 绿 #16bf80 为唯一强调色，无第二种品牌色、无紫色系。 |
| 字体是否有性格？ | 是。Space Grotesk 主字体，非 Inter/Roboto 禁用清单字体。 |
| 图标是否全部来自 iconify？ | 是。全部 lucide 集，零手写 SVG。 |
| 圆角是否只在锁定集合内？ | 是。只使用 {0, 6, 10, 14, 9999}px。 |
| 有没有 Em-dash？ | 否。文案使用中文标点，无 U+2014 / U+2013。 |
| 文案有没有 AI 味？ | 否。功能陈述句，无夸饰动词、无假精确数字。 |
| 有没有装饰性元素？ | 否。无 eyebrow、无装饰状态点、无假版本号。 |
| 对比度是否达标？ | 是。正文 18.1:1，次要 7.7:1，主按钮 8.3:1。 |
| Hero 区是否有渐变背景？ | 否。纯色 #09090b，无光斑、无网格、无渐变。 |
| 特性卡片是否三张同款横排？ | 否。采用一大两小非对称布局。 |

## 12. 设计决策记录

### 12.1 为什么用深色模式作为默认？

- 工作台产品本身就是深色（用户进入后体验一致）
- 深色更显科技感与专业感
- atom 绿在深底上辨识度更高

### 12.2 为什么不用渐变背景？

- 渐变光斑是 AI 生成物泛滥的重灾区（LILA 规则）
- 纯色更显克制与专业
- 与工作台统一，避免"营销页"与"产品"割裂感

### 12.3 为什么特性区用非对称布局？

- 三张同款卡片横排是 AI 套版签名（taste-skill 明确禁止）
- 非对称布局更有视觉张力与记忆点
- 主特性（实时预览）值得更大展示面积

### 12.4 为什么选 Space Grotesk 而非 Geist？

- Geist 是 v0 同款字体，避免视觉上"套壳"
- Space Grotesk 几何骨架更具工程感
- 开源自托管，无外链依赖
