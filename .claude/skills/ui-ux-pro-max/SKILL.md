# UI/UX Pro Max - Litpp Demo 项目版

## 1. 布局体系

### 1.1 双栏工作台模式

本项目核心形态：左侧对话面板 + 右侧预览面板，需遵循以下约束：

| 区域 | 宽度约束 | 行为 |
|------|----------|------|
| 对话面板 | min 360px, max 480px, 默认 400px | 可拖拽调宽 |
| 预览面板 | flex-1 占剩余宽度, min 480px | 低于 480px 时双栏改为上下叠放 |
| 侧栏历史 | 展开 260px, 收起 56px | 仅图标模式 |
| 顶栏 | 高度 56px | 固定 |

### 1.2 响应式断点策略

| 断点 | 条件 | 布局变化 |
|------|------|----------|
| 桌面 | >= 1024px | 双栏并排 |
| 平板 | 768px - 1023px | 双栏并排，对话面板收至 min 360px |
| 手机 | < 768px | 单栏，对话优先，预览可通过 tab 切换 |

### 1.3 首屏布局

- 输入框 max-w 640px，居中
- 模板 chips 左对齐
- 品牌左上角，历史入口右上角
- 避免完全对称的视觉无聊感

## 2. 视觉层级

### 2.1 字号阶梯

| Token | 值 | 用途 |
|-------|-----|------|
| display-xl | 42px / 600 | 首屏标题 |
| title-lg | 20px / 600 | 面板标题、空态标题 |
| title-sm | 14px / 600 | 卡片标题、阶段名、按钮文字 |
| body | 14px / 400 | UI 正文、对话消息 |
| body-sm | 13px / 400 | 次要说明 |
| caption | 12px / 400 | 时间戳、计数、徽章 |
| mono-code | 13px / 400 | 代码视图 |
| mono-metric | 12px / 500 tabular-nums | 计时器、计数 |

规则：全站最小字号 12px，禁止 11px 及以下。

### 2.2 间距节奏

基准 4px，只允许以下值：0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64 px。

典型应用：
- space-1 (4px): 图标与文字间距
- space-2 (8px): 按钮内图标间距
- space-3 (12px): 消息气泡内边距
- space-4 (16px): 面板标准内边距
- space-6 (24px): 输入区与消息列表间距

### 2.3 对比度与留白

| 元素 | 对比度要求 | 备注 |
|------|------------|------|
| 主文字 | >= 4.5:1 | text-primary 对 bg-base |
| 次要文字 | >= 4.5:1 | text-secondary |
| 占位符 | >= 4.5:1 | 复用 text-secondary |
| 禁用态 | 豁免 | text-tertiary 仅用于禁用 |

## 3. 交互模式清单

### 3.1 按钮标准模式

| 类型 | 样式 | 场景 |
|------|------|------|
| 主按钮 | atom-500 底, #09090b 文字, radius-md | 发送、重试、主行动 |
| Ghost 按钮 | 无底, text-secondary, hover 变 text-primary | 次要动作、取消 |
| 图标按钮 | 32x32px 命中区, radius-md 或 radius-full | 工具条动作 |

按压反馈：active 时 scale(0.98), duration 80ms。

### 3.2 输入框标准模式

- 高度：单行 52px，多行最高 160px 后内部滚动
- 聚焦：focus-ring 2px #3dd598 offset 2px
- 字数计数：右下角 mono-metric 格式 `0/2000`
- 超长处理：超出部分无法输入，计数变 danger 色

### 3.3 列表标准模式

- 列表行内边距：space-3 (12px)
- 列表项 hover：border-strong 或 bg-elevated
- 选中态：atom-500 边框或背景 8% 透明叠加
- 骨架屏：shimmer 1.6s linear infinite

### 3.4 空态标准模式

必含三要素：
1. 图标 24px (text-tertiary 或 accent)
2. 标题 (title-lg)
3. 第一个行动入口（按钮或可点击提示）

### 3.5 加载态标准模式

| 场景 | 模式 |
|------|------|
| 面板/列表加载 | 骨架屏 + shimmer |
| 按钮内联 | spinner (lucide:loader-circle 旋转 0.9s) |
| 等待反馈 | 阶段指示器 + 已耗时 + 停止按钮（三要素同屏） |

### 3.6 错误态标准模式

必含三要素：
1. 发生了什么（一句话摘要）
2. 能做什么（恢复路径说明）
3. 至少一个恢复按钮

## 4. 可用性检查清单

### 4.1 键盘可达

- [ ] Tab 顺序合理：首屏（输入框 -> chips -> 提交）, 工作台（侧栏 -> 对话流 -> 输入框 -> 预览工具条）
- [ ] 所有可点击元素可 Tab 聚焦
- [ ] Enter 提交, Shift+Enter 换行, Esc 停止生成/退出全屏

### 4.2 焦点可见

- [ ] focus-ring 全站统一：2px #3dd598 offset 2px
- [ ] 禁止 outline: none 无替代

### 4.3 触控目标尺寸

- [ ] 可点击目标最小 32x32px
- [ ] 触屏最小 44x44px
- [ ] 工具条图标按钮实际命中区 32px

### 4.4 对比度

- [ ] 正文与 UI 文字 4.5:1 以上
- [ ] 占位符 4.5:1 以上
- [ ] 禁用态豁免

### 4.5 屏幕阅读器

- [ ] 生成中状态用 aria-live="polite" 播报阶段切换
- [ ] 错误用 role="alert"
- [ ] 流式文本容器 aria-busy
- [ ] 纯图标按钮必须有 aria-label 或 tooltip

### 4.6 动效降级

- [ ] prefers-reduced-motion: reduce 下：
  - 全部循环动画停止
  - spinner 改为静态圆环加文字
  - 位移类入场改为仅 opacity

## 7. 核心铁律

1. **单一强调色锁定**：atom 绿 #16bf80 是唯一品牌色
2. **边框优先**：面板分隔用 1px border，不用阴影
3. **四态完备**：任何界面必须有 loading/empty/error/success 定义
4. **动效必须有动机**：每个动画需能回答"传达了什么"
5. **拒绝 AI 紫**：无紫色系、无渐变背景、无霓虹光斑
6. **图标来源锁定**：lucide 集，禁止手撸 SVG
7. **圆角锁定**：只允许 {0, 6, 10, 14, 9999}px
8. **间距锁定**：只允许 4 的倍数
