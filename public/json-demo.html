JSON 显示效果演示

1. 短 JSON（少于 10 行，无折叠）

json 
{
  "name": "Atoms Demo",
  "version": "1.0.0",
  "active": true,
  "count": 42
}

2. 中等长度 JSON（默认折叠，可展开）

json 
{
  "project": {
    "id": "proj-123",
    "name": "示例项目",
    "framework": "react",
    "files": [
      {
        "path": "/index.html",
        "type": "html",
        "size": 2048
      },
      {
        "path": "/style.css",
        "type": "css",
        "size": 1024
      },
      {
        "path": "/app.js",
        "type": "javascript",
        "size": 4096
      }
    ]
  }
}

3. 复杂 JSON（多种数据类型）

json 
{
  "response": {
    "status": "success",
    "code": 200,
    "data": {
      "user": {
        "id": 12345,
        "name": "张三",
        "email": "zhang@example.com",
        "verified": true
      },
      "permissions": [
        "read",
        "write",
        "delete"
      ],
      "metadata": {
        "created_at": "2024-01-01T00:00:00Z",
        "updated_at": null,
        "version": 2.5
      }
    }
  }
}
